Start playing

  1. Install the client. Run the Windows setup. Install the Microsoft runtimes if prompted.
  2. Choose your game data. Open AC2 Unreal and browse to your Asheron’s Call 2 folder. It must contain portal.dat, cell_1.dat and local_English.dat. Keep the remaining DATs together.
  3. Enter Dereth. Select Play, then choose offline exploration or a server profile. Hosted servers use their own accounts and data revisions.
